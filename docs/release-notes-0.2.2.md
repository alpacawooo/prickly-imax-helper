# Prickly IMAX Helper 0.2.2

Prickly IMAX Helper는 사용자의 컴퓨터에서 실행되는 CGV IMAX 좌석 감시 및 승인 범위 내 관람권 예매 도우미다. CGV 로그인, 전용 Chrome 프로필, 이메일 주소, 관람권 상태는 사용자 컴퓨터 밖으로 전송하지 않는다.

## 운영체제별 다운로드

- **macOS 전용:** `prickly-imax-helper-0.2.2.tar.gz`
- **Windows 10/11 전용:** `prickly-imax-helper-0.2.2.zip`
- 각 운영체제용 `.sha256` 파일은 다운로드한 설치 파일의 무결성을 독립적으로 확인할 때 사용한다.
- GitHub가 자동 생성하는 `Source code` 압축파일은 설치파일이 아니다.

## 0.2.2 변경사항

- CGV 극장 선택 결과에 `용산아이파크몰 10.3km`처럼 거리 표기가 함께 있는 실제 극장 행도 정확히 인식한다.
- 정확한 극장명 뒤에 숫자와 `m` 또는 `km`만 붙는 유일한 실제 결과만 허용한다. 검색 제안과 비슷한 이름의 다른 극장은 선택하지 않는다.
- 기존 목록형 극장 선택 화면과 거리 표기가 없는 화면도 그대로 지원한다.
- 설정 저장 전 영화·극장·상영 형식 확인 단계의 오류를 수정한 것으로, 좌석·관람권·최종 제출의 안전 조건은 변경하지 않았다.
- Windows 한 줄 설치 명령은 다운로드 폴더와 바탕화면 아래의 하위 폴더에서 압축을 풀지 않은 설치 ZIP을 찾는다.
- 설치 ZIP이 없으면 체크섬을 검사하지 않고 정확한 다운로드 안내만 표시한 뒤 중단한다.

## 유지되는 안전 조건

- 공인 IP 기준 자동 조회 시작 간격은 최소 1초다.
- HTTP 429 발생 시 전체 조회를 최소 5분 중단하고 반복 시 최대 1시간까지 대기한다.
- 같은 행의 설정된 연속 좌석 수만 허용한다.
- 기존 예매 취소와 좌석 변경을 하지 않는다.
- 등록된 IMAX 관람권 수와 선택 좌석 수가 같고 남은 결제금액이 0원일 때만 최종 제출을 한 번 실행한다.
- 제출 결과가 불명확하면 `unknown_after_submit`으로 중단하고 자동 재제출하지 않는다.

## 검증 상태

- 최신 `main` 기준 로컬 자동 테스트 178개 통과
- 실제 CGV 추가 조회 없이 가짜 극장 선택 화면으로 회귀 검증
- 설치 검증 중 좌석, 관람권, 최종 제출 버튼은 누르지 않음

세 사용자 파일럿의 개인정보 없는 기록은 현재 검증기에 등록되지 않았다. 따라서 이 릴리스는 기술 검증 결과를 제공하지만, 세 사용자 파일럿 성공을 주장하지 않는다.
