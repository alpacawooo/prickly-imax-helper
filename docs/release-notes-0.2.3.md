# Prickly IMAX Helper 0.2.3

## 수정 내용

- CGV 좌석 선택 뒤 새로 표시되는 `결제 전 확인해 주세요` 팝업을 팝업 내부의 정확한 `결제하기` 버튼으로만 처리합니다.
- 좌석 클릭 직후 선택 완료 신호가 확인될 때까지 최대 10초 기다립니다.
- 좌석 주문 버튼이 하나만 활성화됐는지 최대 10초 확인한 뒤 클릭합니다.
- 팝업 확인 뒤 관람권·기프트콘 화면이 준비될 때까지 최대 45초 기다립니다.
- 팝업이나 버튼이 중복되거나 비활성 상태이면 임의의 버튼을 누르지 않고 결제 전에 중단합니다.

## 업데이트와 데이터 보존

기존 프로그램을 삭제하지 말고 운영체제에 맞는 `Update.command` 또는 `Update.ps1`을 실행하세요. 업데이트는 버전별 런타임만 교체하며 다음 사용자 데이터는 유지합니다.

- 좌석·상영 조건과 이메일 설정이 들어 있는 `config.json`
- CGV 로그인에 사용하는 전용 `browser-profile/`

업데이트 뒤 `status`가 `armed`인지 확인해야 합니다. 현재 설치기는 사전 dry-run이 실패하면 기존 상주 서비스를 자동으로 되살리지 못할 수 있으므로, 오류가 표시되면 반복 설치하지 말고 상태 화면과 함께 문의하세요.

## 검증 범위와 한계

팝업 유무, 지연 표시, 중복 팝업, 팝업 밖 동명 버튼, 비활성 버튼, 좌석 선택 지연, 관람권 화면 지연을 자동화된 브라우저 회귀 테스트로 확인했습니다. 최종 결제 버튼의 단일 실행 안전장치와 기존 극장 거리 표시 행 선택 로직도 함께 회귀 검사합니다.

실제 좌석이 다시 풀리는 시점 전에는 실제 CGV 화면에서 좌석 선택부터 관람권 화면 진입까지의 완전한 실전 검증을 완료했다고 표시하지 않습니다. 실전 검증은 최종 결제 제출 경로가 코드상 존재하지 않는 QA 전용 probe로만 수행합니다.
