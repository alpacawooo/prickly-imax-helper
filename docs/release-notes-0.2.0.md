# Prickly IMAX Helper 0.2.0

Prickly IMAX Helper는 사용자의 컴퓨터에서 실행되는 CGV IMAX 좌석 감시 및 승인 범위 내 관람권 예매 도우미다. CGV 로그인, 전용 Chrome 프로필, 이메일 주소, 관람권 상태는 사용자 컴퓨터 밖으로 전송하지 않는다.

## 운영체제별 다운로드

- **macOS 전용:** `prickly-imax-helper-0.2.0.tar.gz`
- **Windows 10/11 전용:** `prickly-imax-helper-0.2.0.zip`
- 각 운영체제용 `.sha256` 파일은 다운로드한 설치파일의 무결성을 독립적으로 확인할 때 사용한다.
- GitHub가 자동 생성하는 `Source code` 압축파일은 설치파일이 아니다.

## 0.2.0 변경사항

- 알려진 회차 좌석표를 빠르게 확인하는 조회 4회와 새 날짜·회차 탐색 1회를 균형 있게 순환한다.
- 로그인 손실, HTTP 429, 일시적 통신 오류가 발생하면 실패한 조회가 감시 순서를 건너뛰지 않는다.
- 비어 있거나 오래된 좌석표 응답은 해당 회차를 계속 조회하지 않고 시간표를 먼저 갱신한다.
- CGV 극장 선택창, 당일 날짜 표시, 늦게 나타나는 `일반` 인원 버튼의 변경에 대응한다.
- 당일 회차는 설정과 관계없이 최소 180분의 여유가 있어야 대상이 된다. 사용자는 180~1,440분 범위에서 더 긴 여유 시간을 설정할 수 있다.
- 예매 완료, 결과 확인 필요, 관람권·잔액 차단, 중복 예매 차단 결과를 선택한 이메일 주소로 보낸다. iPhone Mail 수신은 일반 이메일이므로 전송 지연, 집중 모드, 무음 모드의 영향을 받을 수 있다.
- macOS와 Windows 설치기가 이전 정지 표시를 안전하게 처리하고 연결 검사에 성공한 뒤 상주 감시를 다시 시작한다.
- Windows에 한국 시간대 데이터를 포함해 Windows PowerShell 5.1 환경에서도 시간 검사를 동일하게 수행한다.

## 유지되는 안전 조건

- 공인 IP 기준 자동 조회 시작 간격은 최소 1초다.
- HTTP 429 발생 시 전체 조회를 최소 5분 중단하고 반복 시 최대 1시간까지 대기한다.
- 같은 행의 설정된 연속 좌석 수만 허용한다.
- 기존 예매 취소, 좌석 변경, 중복 예매를 하지 않는다.
- 등록된 IMAX 관람권 수와 선택 좌석 수가 같고 남은 결제금액이 0원일 때만 최종 제출을 한 번 실행한다.
- 제출 결과가 불명확하면 `unknown_after_submit`으로 중단하고 자동 재제출하지 않는다.

## 검증 상태

- 로컬 자동 테스트 167개 통과
- GitHub Actions macOS·Windows 설치 및 테스트 통과
- macOS 설치본과 소스 해시 일치 확인
- 10분 상주 감시 검증에서 로그인 손실, HTTP 429, 감시 오류, 결제 전 오류 0건
- 설치 검증 중 좌석, 관람권, 최종 제출 버튼은 누르지 않음

세 사용자 파일럿의 개인정보 없는 기록은 현재 검증기에 등록되지 않았다. 따라서 이 릴리스는 기술 검증 결과를 제공하지만, 세 사용자 파일럿 성공을 주장하지 않는다.
