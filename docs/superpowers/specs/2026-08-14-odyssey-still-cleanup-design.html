THE ODYSSEY
스틸 정리 기준

영화 장면은 그대로 유지한다. 허용된 @fuckinggoodmovies 게시물의 UI 없는 슬라이드 원본을 우선 사용하고, 캡처 복원은 원본 확보가 불가능할 때만 사용한다.

Image 01 · 보조 장면

문제 제기 / 전환 슬라이드
  • 정면 얼굴과 갑옷 디테일 유지
  • 좌우 화살표·하단 점·외곽 웹 UI 제거
  • 잘린 깃털과 인물 형태를 임의로 재해석하지 않음

Image 02 · 메인 장면

표지 / 가치 제안 슬라이드
  • 검정 갑옷과 주황 배경의 대비 유지
  • 좌우 화살표·하단 점·외곽 웹 UI 제거
  • 인물의 윤곽·조명·메달·갑옷 질감 보존
완료 기준
  • 소스: @fuckinggoodmovies 오디세이 슬라이드
  • 최종 출력 1080×1350 JPG 또는 PNG
  • 새 텍스트·로고·워터마크 추가 금지
  • 원본 인물, 갑옷, 색감, 광원 변경 금지
  • 슬라이드 원본을 사용하므로 화살표·페이지 점 제거를 위한 생성형 복원은 하지 않음
