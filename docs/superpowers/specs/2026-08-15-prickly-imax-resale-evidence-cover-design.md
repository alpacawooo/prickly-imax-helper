# Prickly IMAX 리셀 증거형 표지 디자인

## 목표

기존 1장의 시네마틱 분위기와 큰 질문은 유지하면서, `30만 원까지 오른 용아맥 표.`를 짧은 가격 강조 문구로 추가한다.

## 구성

- 캔버스: Instagram 4:5, 1080×1350
- 기본 배경: 기존 오디세이 갑옷 스틸 유지
- 추가 이미지: 사용하지 않음
- 가격 문구: `30만 원까지 오른 용아맥 표.`를 빨간색 44px로 표시
- 제목: `며칠째 새로고침 중인 사람?`을 흰색 86px로 표시
- 정렬: 기존 하단 왼쪽 정렬 유지
- 보조 문구: `나도 그랬음.` 유지
- 하단 표기: 기존 `오디세이 · 용산 IMAX` 유지

## 이미지 처리

- 영화 스틸: 기존 색감·밝기·대비 유지
- 가격 문구만 Prickly 빨간색으로 강조
- 뉴스 화면·플레이어 UI·추가 합성 없음

## 성공 기준

- 모바일 축소 화면에서도 제목이 가장 먼저 읽힘
- 두 번째로 `30만 원까지 오른 용아맥 표.`가 읽힘
- 기존 영화 스틸의 웅장함이 유지돼야 함
- KNN이 Prickly 콘텐츠를 제작하거나 제휴한 것처럼 보이지 않아야 함
- 기존 2~8장의 검은색·시네마틱 톤과 연결됨

## 검증

- 1080×1350 출력
- 제목·페이지 번호·출처 잘림 없음
- 제공 이미지 외 개인정보 노출 없음
- 1장만 변경되고 2~8장 미디어 해시는 유지
- 전체 캐러셀 ZIP과 SHA-256 재생성
