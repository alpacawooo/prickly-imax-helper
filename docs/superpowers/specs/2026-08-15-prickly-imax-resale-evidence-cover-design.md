# Prickly IMAX 리셀 증거형 표지 디자인

## 목표

기존 1장의 시네마틱 분위기와 큰 제목은 유지하면서, 사용자가 제공한 KNN NEWS 화면의 리셀 목록을 실제 문제의 증거로 자연스럽게 결합한다.

## 구성

- 캔버스: Instagram 4:5, 1080×1350
- 기본 배경: 기존 오디세이 갑옷 스틸 유지
- 리셀 증거: 제공 화면에서 상단 판매 목록만 가로로 크롭해 상단 약 40%에 배치
- 제외: KNN의 큰 영상 제목, 재생시간, 플레이어 UI
- 연결: 리셀 목록 하단과 영화 스틸 사이를 검은 그라데이션으로 페이드해 박스 경계를 없앰
- 제목: 현재 큰 제목과 하단 왼쪽 정렬 유지
- 보조 문구: `나도 그랬음.` 유지
- 출처: 하단에 `리셀 사례 화면 · 출처 KNN NEWS`를 작게 표시

## 이미지 처리

- 리셀 목록 채도: 원본의 약 35%
- 리셀 목록 밝기: 원본의 약 55%
- 대비: 제목 가독성을 해치지 않는 범위에서 약하게 낮춤
- 흐림: 텍스트와 가격이 증거로 읽힐 수 있도록 강한 블러 금지
- 영화 스틸: 기존 색감 유지하되 합성 경계 부근만 어둡게 처리

## 성공 기준

- 모바일 축소 화면에서도 제목이 가장 먼저 읽힘
- 두 번째로 여러 리셀 가격이 보임
- 뉴스 캡처를 사각형 카드로 붙인 느낌이 없어야 함
- KNN이 Prickly 콘텐츠를 제작하거나 제휴한 것처럼 보이지 않아야 함
- 기존 2~8장의 검은색·시네마틱 톤과 연결됨

## 검증

- 1080×1350 출력
- 제목·페이지 번호·출처 잘림 없음
- 제공 이미지 외 개인정보 노출 없음
- 1장만 변경되고 2~8장 미디어 해시는 유지
- 전체 캐러셀 ZIP과 SHA-256 재생성
