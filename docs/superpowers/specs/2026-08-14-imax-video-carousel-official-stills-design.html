벤치마킹 범위

전환을 만드는 구조는 배우고, 상대 계정의 시각적 자산과 고유 표현은 가져오지 않는다.

가져오는 것

  • 썸네일에서 페르소나의 문제를 직접 건드리는 방식
  • 한 장에 한 가지 메시지만 두는 구성
  • 실제 결과물과 전달 자료를 영상으로 증명하는 순서
  • 정적인 장면도 짧은 MP4로 만드는 체류시간 전략
  • 마지막 댓글 키워드 하나로 끝내는 CTA

가져오지 않는 것

  • AI Freaks의 이름·마스코트·캐릭터·로고
  • 흰색 격자 배경과 분홍·파랑 색상 체계
  • 캐릭터 시트라는 주제와 상품 구조
  • 상대 계정의 문구·레이아웃·소셜 증거
  • 팔로워 수·참여 수·계정 UI

신뢰를 만드는 세 장

설명보다 실제 화면이 먼저다. 단, 개인정보와 실제 예매 상태를 노출하지 않는다.

완료 기준

시각적 완성도와 제품 안전 경계를 동시에 통과해야 게시 가능한 결과물이다.

출력 QA

  • 8개 MP4와 8개 PNG 커버
  • 전부 1080×1350 · 30fps · H.264 · yuv420p
  • 장면별 6–9초, 무음으로도 의미 전달
  • 모바일 썸네일에서 문구가 한 번에 읽힘
  • 게시 순서와 SHA-256 체크섬 포함

안전 QA

  • 30만 원은 일부 리셀 사례로만 표현
  • 표 보장·CGV 제휴·암표상보다 빠르다는 주장 없음
  • 계정·쿠키·관람권 번호·이메일·비공개 Notion 미노출
  • CGV 조회·좌석·관람권·결제 조작 없이 제작
  • 가짜 티켓이나 가짜 예매 성공 화면 없음
