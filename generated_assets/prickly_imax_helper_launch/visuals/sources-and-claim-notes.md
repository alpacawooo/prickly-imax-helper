# 출처와 표현 범위

## 최종 영상 캐러셀의 오디세이 스틸

- 원본 게시물: `https://www.instagram.com/p/Da0v9PrAJnO/`
- 게시 계정: `@fuckinggoodmovies`
- 사용 근거: 사용자가 해당 계정의 이 게시물 슬라이드를 콘텐츠에 사용해도 된다고 명시함.
- 사용 파일: `content/assets/source-originals/fuckinggoodmovies/odyssey-agamemnon-fullbody-original.jpg`, `odyssey-giants-forest-original.jpg`
- 처리: Instagram UI가 없는 원본 슬라이드를 1080×1350으로 비생성형 크롭함. 인물·갑옷·색감·배경은 변경하지 않음.
- 범위: 유기적 편집 콘텐츠 기준. 유료 광고나 별도 상업 매체 집행은 권리 범위를 다시 확인해야 함.

## Card 2 IMAX 비교 자료

- 사용자 제공 파일: `content/assets/imax-comparison/the-direct-35mm-vs-imax70mm-user-reference.png`
- 화면 내 출처 표기: `THE DIRECT` 워터마크를 제거하거나 가리지 않음.
- 표현 범위: 35mm와 IMAX 70mm의 프레이밍 차이를 보여주는 비교 예시.
- 형식 주의: 용산 CGV의 화면에 표시된 형식은 `IMAX LASER 2D`이므로 같은 상영 형식이라고 주장하지 않으며 Card 2 하단에 차이를 명시함.
- 재배포·유료 광고 사용 전에는 원저작물 사용 범위를 별도로 확인해야 함.

## Card 3 실제 CGV 문제 화면

- 사용자 제공 파일: `content/assets/cgv-evidence/odyssey-yongsan-single-seat-20260815.png`
- 화면에 표시된 사실: 오디세이·용산아이파크몰·IMAX 회차 중 `1석/624석`과 좌석표의 떨어진 한 자리.
- 허용 표현: `자리 있다고 떠서 들어가도 붙어 있는 2석은 없다.`
- 금지 표현: 이 화면만으로 좌석이 사라졌거나 다른 사용자가 먼저 잡았다고 주장하지 않음.
- 개인정보: 계정명, 이메일, 쿠키, 관람권 번호, 예매번호가 보이지 않는 것을 확인함.
- 제작 과정에서는 저장된 이미지만 사용했으며 CGV에 추가 요청하지 않음.

## 배경 이미지

- 제작 방식: OpenAI 내장 이미지 생성
- 저장 파일: `assets/cinema-background.png`
- 최종 프롬프트: `Photorealistic empty premium large-format cinema auditorium, viewed from the back rows toward a monumental blank screen. The screen shows only a subtle abstract dark-red glow with no text, logos, film characters, posters, or recognizable intellectual property. Black seats, charcoal walls, sparse ceiling lights, restrained red aisle lights, cinematic low-key lighting, realistic architecture and lens perspective. Vertical 9:16 composition, with generous dark negative space across the upper and middle screen area for Korean editorial typography; keep important architecture inside a crop-safe central 4:5 area. No people, no brand marks, no watermark.`
- 사용 범위: 배경 및 분위기 연출 전용. 실제 CGV 상영관이나 특정 영화 장면으로 주장하지 않음.

## 제품 화면

- `assets/helper-setup-preview.png`: 저장소의 실제 Prickly IMAX Helper 설정 UI를 오프라인으로 렌더링한 화면
- `assets/helper-monitor-preview.png`: 설치된 CLI의 로컬 `diagnose` 결과에서 상태·열린 날짜 수·조건 충족 회차 수·`match:null`·오류 수만 추려 오프라인 렌더링함. 계정, 쿠키, 관람권 번호, 예매 시도 ID, 프로필 경로, 시간은 표시하지 않음.
- Card 5는 실제 설정·redacted diagnose 화면과 Prickly 단계 문구를 조합해 작동 순서를 보여줌.
- Card 7은 `조건 일치 → 안전검증 → 최종 제출 1회 → 결과 이메일`이라는 제품 흐름만 표현함.
- 모바일티켓, 예매번호, QR, 바코드, 실제 예매 성공 화면은 만들거나 사용하지 않음.

## 여론 표현

- 사용자가 제공한 인스타그램 스크린샷에서 반복된 정서인 `매진`, `취소표가 금방 사라짐`, `IMAX 관람 포기`, `고가 리셀 사례`를 구조화함.
- 계정명과 원문 댓글은 사용하지 않고 익명·재서술한 문장만 사용함.

## 광고·주장 안전선

- `10만 원 넘는 표`는 사용자가 제공한 여론 자료의 일부 리셀 게시물 사례로만 표시하며 일반 거래 가격이라고 말하지 않음.
- 좌석 확보를 보장하지 않음.
- CGV의 공식 제품, 제휴 제품, 추천 제품으로 표현하지 않음.
- 암표상보다 빠르다거나 반드시 경쟁에서 이긴다고 표현하지 않음.
- 사용자 본인 컴퓨터·본인 계정·등록된 IMAX 관람권을 전제로 함.
- 카드 결제 자동화를 제공한다고 표현하지 않음.
