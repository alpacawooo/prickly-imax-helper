# Reel Script

목표 길이: 27–30초  
형식: 실제 Helper 화면 녹화 + 개인정보를 가린 CGV 화면 + 키네틱 타이포

## 0–3초 — 후킹

화면 문구:

> 용아맥 한 자리 보는데 30만 원?

내레이션:

> 용아맥 한 자리 보는데 30만 원?

화면/편집:

- 커뮤니티에 올라온 고가 리셀 사례를 가격과 반응만 보이도록 재구성한다.
- 첫 프레임 하단에 작게 `일부 리셀 게시물 사례`라고 표시한다.
- 실제 계정명, 프로필 사진, 게시물 ID는 모두 가린다.

## 3–7초 — 문제

화면 문구:

> 열어보면 전석 매진
> 취소표는 몇 초 만에 사라짐

내레이션:

> 앱을 열 때마다 전석 매진. 취소표는 보여도 몇 초면 사라져.

화면/편집:

- `전석 매진`, `아직 IMAX로 못 봄`, `용아맥은 포기` 반응을 빠르게 겹친다.
- 실제 CGV 좌석을 잡는 장면처럼 연출하지 않는다.

## 7–11초 — 해결책 공개

화면 문구:

> 사람 대신
> 내 컴퓨터가 기다리게 했다

내레이션:

> 그래서 사람 대신 내 컴퓨터가 기다리게 만들었어.

화면/편집:

- Prickly IMAX Helper 설정창이 열리는 실제 화면 녹화.
- 제품명은 한 번만 작고 선명하게 노출한다.

## 11–18초 — 사용 흐름

화면 문구:

> 1. 설치
> 2. 전용 Chrome에서 직접 로그인
> 3. 원하는 조건 설정

내레이션:

> 설치하고 전용 Chrome에서 직접 로그인한 뒤, 영화·시간·인원·원하는 열만 고르면 돼.

화면/편집:

- 설치 완료 → 전용 Chrome 열기 → 조건 설정 순으로 1.5–2초씩 보여준다.
- 비밀번호, 쿠키, 이메일, 관람권 번호는 화면에 담지 않는다.
- 영화·극장·포맷·시간·인원·열이 변경 가능하다는 부분을 짧게 스크롤한다.

## 18–23초 — 감시 결과

화면 문구:

> 지금 열린 날짜 + 앞으로 열릴 날짜
> 내 조건의 연속 좌석을 기다림

내레이션:

> 그러면 지금 열린 날짜부터 새로 열릴 날짜까지, 붙어 있는 좌석을 계속 확인해.

화면/편집:

- `armed`, `match: null` 상태를 개인정보 없이 보여준다.
- `null`은 실패가 아니라 현재 조건에 맞는 좌석을 기다리는 중이라고 자막으로 풀어준다.
- 가짜 좌석 발견이나 가짜 모바일티켓을 만들지 않는다.

## 23–27초 — 안전장치

화면 문구:

> 내 계정 · 내 IMAX 관람권
> 잔액 0원 확인 후 1회만

내레이션:

> 내 관람권 수와 잔액 0원을 확인한 뒤 한 번만 제출해. 그렇다고 표가 반드시 생기는 건 아니야.

화면/편집:

- `중복 예매 차단`, `관람권 수 확인`, `잔액 0원`, `1회 제출`을 체크 애니메이션으로 표시한다.
- 카드 결제 자동화나 성공 확정으로 오해할 화면은 사용하지 않는다.

## 27–30초 — CTA

화면 문구:

> 댓글에 “아이맥스”
> 설치 방법 보내줄게

내레이션:

> 써보고 싶으면 댓글에 “아이맥스”라고 남겨줘.

화면/편집:

- 마지막 2초 동안 댓글 키워드를 고정한다.
- 공개 설치 링크와 안내문이 실제로 준비된 뒤 게시한다.
